# Chalamandra 6 Sombreros de De Bono - Entrenador Cognitivo Adaptativo

Sistema interactivo de toma de decisiones y entrenamiento cognitivo basado en el método de los **6 Sombreros para Pensar de Edward de Bono**, impulsado por **Gemini 3.5 Flash** y personalizado con los personajes estratégicos **La Chola (Chalamandra)**, **La Fresa** y **La Malandra**.

## 🎩 Los 6 Sombreros
- ⚪ **Blanco**: Datos puros, cifras y hechos objetivos.
- 🔴 **Rojo**: Intuición, emoción y corazonadas sin filtro.
- ⚫ **Negro**: Cautela, riesgos, costos ocultos y lógica crítica.
- 🟡 **Amarillo**: Optimismo, oportunidades y beneficios tangibles.
- 🟢 **Verde**: Creatividad disidente, pensamiento lateral y alternativas.
- 🔵 **Azul**: Control del proceso, metacognición y prioridades tácticas.

## 🚀 Características
- **Ruleta Cognitiva Adaptativa**: Calibra tus sesgos mentales en tiempo real.
- **Tutor Interactivo Gemini 3.5**: Modal flotante y pestaña con diálogos multi-turn adaptados a la personalidad de Chalamandra.
- **Visualizador de Coherencia IA**: Analiza y mapea el equilibrio entre sombreros.
- **Persistencia en Firestore**: Guarda tus rituales y progreso.

## 🛠️ Desarrollo Local

```bash
npm install
npm run dev
```

Desarrollado con React, Vite, TypeScript, Tailwind CSS, Firebase Firestore y Google Gemini API.
